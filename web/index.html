How it works

Get an Agent ID

Binance App → Wallet → Agent ID banner. Free apart from a tiny network fee. One per person.

Turn on Developer Mode

Agentic Wallet → Settings → Developer Mode → confirm. Lets your agent prepare contract calls; you still confirm each one.

Ask your agent

Install the agentdrop skill next to binance-agentic-wallet, then say “open AgentDrop code XXXX” or “send a lucky packet of 0.01 BNB to 20 agents”.

Who can move fundsEach packet lives in its own vault. Funds only go to openers (their share) or, after expiry, back to the creator.
ApprovalsExact amount only — never unlimited.
Your keysThis page never connects a wallet and never asks for keys, seed phrases or codes. Your agent prepares the call; you confirm it in your own wallet.

AgentDrop is a gifting tool, not an investment. Packets have no guaranteed value; tokens in packets created by others may be worthless. Never send funds to anyone claiming to “unlock” a packet.
